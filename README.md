# Vue + Vite + Tailwind Starter

Minimal frontend starter template built with:

- Vue 3
- Vite
- Tailwind CSS

This repository is intended to be used as a starting skeleton for new frontend projects.

---

## 📦 Tech Stack

- Vue 3
- Vite
- Tailwind CSS
- PostCSS

---

## 🚀 Getting Started

### 1. Clone repository

git clone https://github.com/Baxtibay/vue-tailwind-starter

cd your-repo-name

### 2. Install dependencies

npm install

### 3. Start development server

npm run dev

---

## 🏗 Build for Production

npm run build

### Preview production build

npm run preview

---

## 📁 Project Structure

src/  
 ├── assets/        # Static assets  
 ├── components/    # Reusable components  
 ├── layouts/       # Layout wrappers  
 ├── pages/         # Page-level components  
 ├── styles/        # Global styles  
 └── main.js        # Entry point

---

## ⚙️ Requirements

- Node.js >= 18
- npm >= 9

---

## 📌 Notes

- `node_modules` and `dist` are ignored in Git.
- This repository is intended to be used as a template.
